# PR #6：固定主面板与图标旁三行弹幕

2026-10-19；本机候选 `1.2.0-rc.6`，正式版目标仍为 1.2.0。
视觉与手势效果已获用户验收；本轮只向个人 fork 工作分支追加提交，不创建或重开 PR。
接续净化后的历史并保留协作 CI，不改变已验收效果、DSH 依赖或业务结算。

## 现行设计

- **主面板固定**：删除弹幕驱动的间距属性、位置状态、回调和位移过渡；弹幕新增、
  挤出、超时均不改变面板坐标或尺寸。面板打开只有短暂透明度变化。
- **使用现有空白**：弹幕顶端对齐 42px 梁子图标的顶端（48px 点击区内缩 3px），
  默认出现在图标右侧、主面板这一列内，向下放三行；右侧停靠时向内镜像。
  靠近视口底部或下方有主面板时减少行数，始终不移动面板或向上挤压图标。
- **独立短句**：每句按文字宽度收拢，没有共同底框或尾角。行距 22px，日间暖白、
  夜间抬升灰底，活跃文字保持清楚可读。普通今日梁相提示在拍打时让位，结束后恢复。
- **三段节奏**：新句用 160ms 从 3px 微小位移轻显；新句加入后，旧句用 300ms
  平滑下移一格；挤出/超时的句子在 420ms 内再下沉约 19px 并淡去，之后才移除。
  预留 20px 退出空间，不裁切文字；区域高度和顶端保持固定。减少动态时关闭位移。
- **保留明确手势**：单击经 200ms 短判定打开/收起；只有间隔内的双击/连拍玩耍，
  面板原本开或关都保持原状。键盘立即开合，×/Escape 立即关闭；拖动/取消清除待定
  单击，不发玩耍声音。玩耍不改投票、余额、梁子等级或模式。

## 验证重点

- 默认停靠三条活跃句，弹幕顶端与图标顶端对齐；左右边、上/下角及窄屏均在视口内。
- 从首拍到文字全部退场，逐帧记录主面板坐标和尺寸，最大变化必须小于 0.1px；
  不能只比较动画前后的相同坐标。
- 退出行在屏幕上的 y 增加、透明度介于 0 与 1，整个字行仍在退出空间内，完成后移除。
- 保留单击收起、间隔 260ms 的两次点击、短间隔双击保持开/关状态、拖动/取消、
  键盘焦点、减少动态、无业务 POST 和实际日/夜主题文字对比度至少 4.5:1 的检查。
