# PR #6：入口与旁白再设计

2026-10-19；基线 `7c78344`，候选 `1.2.0-rc.4`，正式版目标仍为 1.2.0。
#6 已合并关闭，本轮只追加新 commit，不重开或新建 PR。

## 问题与方案

旧版三条独立小框绕到主面板侧边，形成割裂的第二列；旧句尚未到期就被数组截断，
没有退场阶段。按年龄持续降低可见度也使夜间旧句近乎不可读。单击等待 400ms 后再
开始面板入场，叠加造成明显迟滞。

- **入口即时**：单击、Enter、Space 立即打开并聚焦。打开后，指针点击只拍打；
  × / Escape 统一即时关闭。关闭状态双击只打开一次，后续每拍回应，不再判定双击。
  这是为消除开合等待而明确改变的入口行为；徽标不再承担“再次单击关闭”。
- **一块连贯旁白**：文字共用一个纸笺式表面、小尾角与暖色细标记，不再逐句加框。
  浅色为柔暖纸面，深色为有清楚边界的抬升炭色；活跃文字保持完整不透明度。
- **保持一列**：旁白连在图标内侧，横向始终收在主面板范围内。它以图标边缘为界
  展开，主面板同步轻移腾出空间，最多移动 32px。面板入场本身为 110ms 轻显。
  可用高度不足时减少行数，保护视口与主面板；默认停靠的旁白底边不超过图标底边，
  不压到底部宿主菜单。没有新增业务区域。
- **统一退场**：新句进入时旧句逐行下沉；被挤出与超时的句子都进入 200ms
  淡出/下沉阶段，完成后才移除。最多三条活跃句、两条正在退场的句，持续连拍有界。
  单句正常停留 2.4s，退场完成约 2.6s；拖动、取消与关闭清理展示，不改变业务状态。
- **提示与无障碍**：默认今日梁相提示在按压/旁白期间让位，结束后恢复；普通提示
  仍只在真实视口边界才贴边。键盘打开不发装饰旁白。减少动态时关闭位移、回弹和过渡。

实现范围为 Badge、BadgeFeedback、纯布局/保留队列与 Panel 的装饰间距；未改变
小难梁规则、历史规则版本、用量结算、投票、余额、模式或 DSH 运行依赖。

## 验证要点

- 真实鼠标点击到 aria-expanded 变化测量，打开/关闭均须低于 100ms；连续点击和
  停顿后再点击只产生首次打开，不出现中间关闭。
- 验证挤出行退场时仍在 DOM、透明度介于 0 与 1，结束后移除；超时走同一保留规则。
- 默认停靠、左右边、上下角及中部：单一旁白面保持在主面板列内，与图标相连，
  不覆盖面板正文或超出视口。窄屏同样验收。
- 检查真实 DSH 深色主题的文字对比度至少 4.5:1，而非仅模拟系统偏好。
  宿主保存的主题可能覆盖系统偏好，因此浏览器助手在不匹配时通过公开 Settings →
  Appearance 选择实际明暗主题，并核对根元素的 color-scheme。
- 保留拖动/取消安静、键盘焦点、减少动态、无业务 POST 的回归；完成现有完整安装
  包浏览器检查及常规 verify 后再提交推送。

本轮手测继续使用独立的 localhost Profile / SQLite，不公开发布，也不部署生产。
