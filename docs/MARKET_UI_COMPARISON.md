# 交易视图：当前方案与参考边界

当前 `1.3.0-alpha.2` 候选采用统一的香火交易窗口与单批操作，尚未正式发布。潮汐表现层曾参考同项目的 MIT 设计提案 `design/tide-chart/liangzi-tide-chart.html`，保留贡献者版权；参考不替换服务器账本或数据来源。

## 当前视觉

- 案牍只保留一个香火交易入口。默认看 K 线，也能切换蓝色潮汐；原主面板四区、梁子素材与互动不变。
- 官方五分钟行情在全天视图聚合为十五分钟烛线，窄屏可用三十分钟；近四小时保留五分钟精度。涨跌双色、数字纵轴和独立的开／高／低／收／时间列用于读数，支持缩放、平移、逐烛与全屏查看。
- 全天天轴覆盖 00:00–24:00，P1/P2/P3 标记真实定线时刻。开盘前、投入、锁仓定线与尾盘以轻微底色区分；未来留白并显示「待打梁」。坐标范围按当前可见数据计算，避免窗口外极值把走势压扁。今日、近4时和分钟精度保持固定位置及宽度。
- 鲸鱼沿用现有插画，在标题旁以约六十六像素展示，不再占用图表宽度。浮水／潜水仍表达当前所选仓位的占优状态，不代表已结算收益；局部鱼尾、发梢和呼吸保留，操作时短促回应，气泡与角色分行避让。
- 原巨大夯拉气泡改为图底独立分色量带：高度表示总量，分段表示已确认夯拉比例，未知分量保持中性；悬停或点击固定读数。
- P1/P2/P3 切换共用固定高度的单批操作区，保留未提交草稿；锁仓、保存和错误状态不推动窗口跳动。回执与玩法使用常驻按钮打开浮层，不展开页面高度。
- DS 蓝、纸面、圆润描边和底影统一到按钮与图表；早午晚盘、方向及确认按钮使用同一组凸起、下压与回弹反馈。明确的「大肥鱼 · 动态／大鱼干 · 静态」控制装饰动作，静态、减少动态、隐藏或关闭时停止装饰循环。右下角固定显示「24:00后一起揭晓」。

## 数据边界

烛线聚合仅汇总真实官方样本：开取首笔、收取末笔、高低取有效极值，投票量只汇总已确认分量。缺柱、null 与换案不硬接；不能把本机一分钟观察伪装成官方一分钟行情。

潮汐在官方末值之间采用单调受限曲线：穿过真实锚点、不超出相邻端点，缺柱、null 与换案不连接。平滑仅用于画水线；读数、当前点、P1/P2/P3 定线及结算仍取原始票数，不从曲线取价。水体动效不推算未来价格或未到账收益。

当前点与批次参考保留真实时间及比例；角色只可为避让而移动，不能挪动官方点。业务日与夏令时使用服务器时区和实际日长。原本机观察的 Host 采样、历史与只读出图接口保留，与市场官方数据分离。

服务器不保存动画、截图或材质状态；钱包、冻结、整数分池和午夜结算规则不变。原主面板的梁子素材及互动效果保持原样。
