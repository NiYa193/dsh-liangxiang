# 交易视图：当前方案与参考边界

当前 `1.3.0-alpha.3` 为未发布候选。潮汐表现层曾参考同项目的 MIT 设计提案 `design/tide-chart/liangzi-tide-chart.html`，保留贡献者版权；表现层不替换服务器账本或价格依据。

## 当前界面

- 案牍四个工具格压紧，香火交易作为更大的独立菜单行，配小型装饰烛线。缩略图没有价格含义，也不请求行情。
- 普通窗口采用紧凑高度；全屏才展开。标题区、阶段切换、方向／金额／确认和底部反馈按固定槽布局，切换早午晚盘、持仓或回执不推动窗口跳动。
- 阶段为轻量分段标签，方向与金额紧邻确认动作；只有主要确认按钮强调填色，保留轻微下压与回弹。持仓与预计返还在订单下面的小行显示，撤回复用该行。
- 默认 K 线，保留潮汐、分列开高低收、数字轴、缩放／平移／全屏。自动粒度随缩放改变，也可直接选1／5／15／30分钟；固定宽度的选择器不挤压相邻控件。
- 时轴覆盖业务日00:00–24:00，开盘前也展示已记录的真实走势；淡色底仅标记投入与锁仓时段。未来仍留白并显示「待打梁」，P1/P2/P3 保持真实定线坐标。
- 原鲸鱼插画放在标题旁，与两行台词分开。水上、水下、等候及明确操作有对应对白，局部鱼尾、发梢、呼吸与小幅游动保留；回执确认后的回应只在 Host 返回已接受状态后出现。
- 静态、减少动态、隐藏或关闭时停止装饰循环。待机文字只在动态可见时低频轮换，操作回应短暂展示；不刷屏播报，不参与账务或发送网络数据。
- 回执与玩法常驻底栏并以浮层打开；24:00后统一揭晓。错误提示复用浮层槽，不增加空白行。

## 数据边界

schema 14 使用独立官方分钟表，旧五分钟表保留只读。记录按真实粒度传输和缓存；旧后台只能提供五分钟时，1分钟选项不可用，不把历史拆成虚构的小柱。

每页最多288根，首次仅按游标取齐当天，常规冷校准沿用五分钟节奏；分钟实时桶复用已有推送。浏览器缓存总量最多2MiB，过量按旧日淘汰，不缓存余额作为权威。全年分钟数据的本机尺寸证据见验证记录，不等于服务器压测。

烛线聚合取真实首开、末收、有效极值与新增票量；缺柱、null、换案不硬接。潮汐曲线仅连接已知锚点，不超出相邻端点，也不参与读数、定线和结算。颜色仅表达已确认夯拉分量，未知体量保持中性。

本机观察 Host 的一分钟采样与出图接口保留，和官方行情分离。服务器不保存动画或截图；原主面板梁子素材、互动、钱包冻结、投票与整数结算保持各自边界。
