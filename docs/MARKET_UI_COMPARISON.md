# 交易视图：当前方案与参考边界

当前客户端采用完整的水塘场景与单批操作。参考源为同项目的 MIT 潮汐设计提案 `design/tide-chart/liangzi-tide-chart.html`；表现层适配保留贡献者版权，不替换服务器账本或数据来源。

## 当前视觉

- 纸面、点阵桌布、细墨色边框与底影构成实体层次；DS 蓝集中在水体。圆润水线、上深下浅的渐变、池底波浪与鹅卵石形成完整池塘。
- 水深固定 0–100%。右侧层级胶囊与当前带高亮只使用同一梁案已验证的梁子规则；规则缺失、未知或梁案不匹配时不猜测层级。
- 事件气泡具有纸色描边。只有已确认的夯拉分量才表达方向；不明部分保持中性。金点保留真实坐标，金边梁位徽章避让角色，不遮脸。
- 使用独立生成的鲸鱼娘位图，分离尾巴、发梢和呼吸动作；所选批次决定浮水或潜水。水上露出主体并有涟漪，水下有渐隐遮挡、蓝色浸染与吐泡泡；静态也保留这两种姿态。保留原插画，不用整张图片上下浮动代替局部动作。
- P1/P2/P3 为三个可键盘切换的标签，每次只操作一批；未提交草稿在切换后保留。奖池明细、历史和规则默认折叠。
- 窄屏保留真实梁位、当前层级与可操作批次，收起不易辨认的细注。按钮使用独立凸起表面，按下下沉、松开回弹；水体有受真实水域裁切的缓慢光纹。静态、系统减少动态、隐藏或关闭窗口时停止装饰循环及过渡。

## 数据边界

按最新视觉反馈，官方五分钟末值之间采用单调受限曲线连接：穿过真实锚点，不超出相邻端点，缺柱、null 与换案不连接。平滑仅用于水线画法；悬停读数、当前金点、定线与结算仍用原始样本和票数，不从曲线取价。水体光纹限于已记录水域，不推算未来价格或未到账收益。

当前点与 P1/P2/P3 均保留真实时间、原始票数和比例；角色与徽章只可为避让边缘而移动，不能移动官方点。时间轴默认覆盖服务器业务日 00:00–24:00，夏令时按实际业务日长度定位。未来区标记「尚未发生」，只展示批次日程，不画虚构走势；形成中的烛线不向未来定位。近四小时仍是主动选择，不作为默认。

服务器不保存动画、截图或材质状态；钱包、冻结、整数分池和午夜结算规则不变。原主面板的梁子素材及互动效果保持原样。
