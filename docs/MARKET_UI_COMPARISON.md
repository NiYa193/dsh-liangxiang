# 交易视图：独立实现后的设计对照

独立实现基线为 `9cdf057`，先完成累计钱包、三批分池、官方行情、鲸鱼娘反馈及真实安装验证，再阅读 MIT 潮汐图设计提案（`design/tide-chart/README.md` 与 `liangzi-tide-chart.html`）。对照不改变后台账本、结算规则或数据来源。

采用的两项表达：

- 默认以蓝色水位呈现五分钟末值，保留可切换的 OHLC 烛线。使用自行实现的阶梯几何；缺失柱与无有效比率处断开，不平滑、不补画。潮汐纵轴按所画的末值和官方参考点取范围，烛线仍保留真实高低值。
- 官方 `volume` 聚合为半小时事件气泡，每日最多 48 颗，仅近期最多三颗可轻缓浮动。只有相邻官方累计计数的差额恰好等于该柱总量时才展示夯拉明细；其他情况只报告本场已记录总量。

保留独立生成的鲸鱼娘素材、P1/P2/P3 真实数据坐标、键盘浏览、主题与动态/静态开关。没有复制提案中的角色 SVG、平滑曲线、手造事件数据或硬编码六态深度带。服务器权威行情不改用本机观察账本。

动画与提示均由客户端派生，不新增网络字段或缓存。减少动态、静态选择、隐藏和关闭窗口时不运行装饰循环。个人钱包与结算回执仍只由服务器确认。

验证补充包含阶梯时间位置、缺柱/null 断线、零票不造值、末值与 OHLC 纵轴隔离、气泡总量和已确认方向、粒子数量/尺寸上限，以及真实安装浏览器中的潮汐/烛线切换和缺口几何检查。
