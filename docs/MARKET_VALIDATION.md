## 后台磁盘采样

采用一次性文件 SQLite、46 字符安装身份、36 字符请求 UUID，分别执行 10,000 笔后 `wal_checkpoint(TRUNCATE)`，比较主库净增长；不是线上观测或年度容量承诺。

| 操作 | 10,000 笔净增长 | 说明 |
| --- | ---: | --- |
| 每次 +1 Token，合计尚未满一炷 | 0 字节 | 余量、版本和游标持久更新，不新增零金额流水；仍有 WAL 写入与 I/O |
| 每次 +50,000 Token，真正生成一炷 | 2,654,208 字节 | 新增 10,000 条资金流水，约 265 字节/笔 |
| 修改汇总仓位 | 5,484,544 字节 | 约 548 字节/笔，含幂等请求与资金流水；仓位仍只有一行 |

因此一年是否约 1 GB 取决于活跃人数、实际生香、上香、改仓和结算笔数，还要加上索引、日志、备份等。不能只按每天三个仓位估算。资金流水不随客户端下载；收盘回执使用一次按身份分组，避免人数增长时反复扫描全场仓位。

- 2 CPU / 4 GiB 是部署目标，尚未在该实际规格压测，不能从本地单元测试推出连接容量。
