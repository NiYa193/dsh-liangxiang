## 传输与缓存实测样本

| 内容 | 开发样本 |
| --- | --- |
| 浏览器客户端 | 约 668 KB 原始、413 KB gzip；比原基线新增约 14 KB gzip |
| 按需鲸鱼 WebP | 23,084 字节，不内嵌客户端脚本 |
| 压缩安装包 | 约 1.0 MB；不含 DSH 本体首次安装依赖 |
| 本人钱包与当前场次 | 1,487 字节原始、562 字节 gzip |

每次首次行情最多 288 根；个人回执默认 20、最多 50 条。交易业务缓存上限 2 MiB，行情七日、回执三十份；本地不保存权威余额。缓存和安装包不会复制全社区年度历史。

## 安全与上线边界

- 迁移、重启、跨日赠香、冻结/投票并发、整数守恒、丢回执、身份恢复竞争和未知规则均有回归。
- 身份签名不证明 Token 来源真实，保留社区软信任标识。
- 候选 schema 13 不得直接部署到当前线上维护版。新后台需要支持累计钱包协议的客户端；不能伪造今日用量来兼容旧公式。
- 2 CPU / 4 GiB 是部署目标，尚未在该实际规格压测，不能从本地单元测试推出连接容量。
- 变更凝香阈值须独立迁移；与持久钱包不符时启动即拒绝，不在用户领取赠香时才失败。
