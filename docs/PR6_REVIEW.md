# PR #6 — 梁子徽标与趣味反馈

来源：[PR #6](https://github.com/liang-today/dsh-liangxiang/pull/6)。
感谢 [@XChen446](https://github.com/XChen446) 带来的果冻徽标创意与实现。

## 现行行为

徽标轻拍提供即时按压、回弹和短音；短间隔双击/连拍显示独立短句。
单击在 200ms 手势分类后开合主面板；双击/连拍保持面板原本的开关状态。
键盘即时开合，拖动与取消不发玩耍声音，所有路径清理待定操作。

主面板全程固定。短句放在图标旁现有空白内，顶端与梁子图标对齐，最多三行；
新句轻显、旧句逐行下落，挤出和超时统一下沉渐隐。普通“今日梁相”提示按实际
视口边缘对齐，拍打期间让位。浅色、深色、窄屏及减少动态均有独立检查。
精确布局和动效契约见 [最终反馈设计](PR6_FEEDBACK_REDESIGN.md)。

可访问名称保持“今日梁相”；键盘不触发装饰弹幕。趣味反馈不增加投票入口、
业务区域或个人等级，不发送投票、改变香火或影响社区梁位；不增加运行时依赖。

  清单的相对资源地址和旧 HTML 入口。

  两个投票动作、焦点、可访问性和真实安装行为。
