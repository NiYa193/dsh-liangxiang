## 审查结论

果冻徽标是低成本、可发现的趣味反馈：一枚现有控件的轻拍回弹、短音和连拍彩蛋，
不增加第五区、按钮、成长系统或业务数据，符合克制的产品方向。整枚 button 变形、
tooltip 在外保持稳定的结构合理；沿用合成音效，不新增媒体或运行时依赖。

原稿不能直接合入正式主线：

- pointerdown 就播音，拖拽/取消也会响；改为确认轻拍后在回弹时发声。
- 第三次起吞掉所有 click，包含 Enter/Space/辅助技术激活；改为只处理指针连击，键盘始终保留正常开合。
- 文案包含禁用旧称呼和暗示漏香的说法；改为纯装饰短句，可访问名称与默认悬停保持今日梁相，玩耍不影响业务状态。
- 减少动态只停回弹，按压仍变形；改为禁用按压与回弹变形，取消手势也清理状态。
- 原稿强制读取 offsetWidth 重启动画；改为按下清除、释放重放，移除动画重启时的强制回流与常驻 will-change。
- 原稿没有升用户可见版本；本地整合候选统一升级版本和更新提示，不宣称公开发布。

## rc.2：按手工反馈统一交互

rc.1 的前两拍即时开合、第三拍才进入玩耍，会让双击反复闪开/关闭；旧长提示
一律贴边，也没有按文本实际宽度决定对齐。rc.2 用互斥的待定单击/玩耍状态替换计数阈值：

| 操作 | 统一行为 |
|---|---|
| 单击 | 按压立即响应，释放回弹/短音；等 400ms 判定不是双击，再开合一次 |
| 双击 | 第二次按下取消待定单击，第二次释放开始弹幕，面板状态不变 |
| 继续连拍 | 每次轻拍都有按压/回弹；每 140ms 最多一句，最多三行，停顿 750ms 结束连拍 |
| 停顿后再双击 | 重复相同规则，不闪开面板；单击恢复正常开合 |
| 键盘 Enter/Space | 即时开合，清除待定单击与弹幕，避免迟到的反向开合 |
| 拖动、取消、Escape、关闭 | 取消待定操作；拖动/取消不发声、不回弹 |
| 悬停/键盘焦点 | 短暂悬停后显示今日梁相；按压及弹幕期间隐藏，结束后恢复 |

弹幕最新一句在上，旧句用 220ms 缓动逐行下沉；每句最多停留 2.6s，到期淡出并轻沉；
满三行时最旧一句让位。
八条短句随机但不连续重复，不堆连击数字或新按钮。减少动态时静态呈现，到时移除。
默认提示与弹幕独立；删除会与自定义提示争抢的原生 title，保留完整可访问名称。

提示与每批弹幕实测自身宽度，只有居中会超出视口时才贴左/右边。弹幕以三行小区域排布，
先找徽标上下空间，再避让实测主面板到侧边；窄屏侧边不足则用面板上方/下方空位。
面板尺寸变化和入场结束都会重新量取；短弹幕收拢到实际宽度，避免窄屏被宽空白挤到远处。
找不到完整空位时不遮住面板或图标。徽标原先用于容纳 tooltip 的外层容器已移除，
沿用原有构建和 DSH loader 包装。
布局逻辑集中在 badge-feedback.ts，DOM 测量与表现集中在 BadgeFeedback.tsx；
手势/计时器留在已有容器，玩耍仍不写业务字段、不发投票、不改变香火/梁位/中央状态。
